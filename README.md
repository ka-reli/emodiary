# ☽ EmoDiary — эмо-дневничок для SillyTavern

Расширение дописывает к сообщениям в чате HTML-блок «личного дневника» в эстетике
западного веба 2000-х (LiveJournal, MySpace, Xanga): тёмный фон, розовый неон,
каомодзи, xD, rawr, ~\*~decorations~\*~, поток сознания без заглавных букв
и счётчик комментов на нуле.

Записи генерирует **отдельная недорогая модель** через ваш собственный
OpenAI-совместимый эндпойнт — токены основной игровой модели не тратятся,
и дневничок **не попадает в её контекст** (он хранится в `message.extra`
и дорисовывается в интерфейсе поверх сообщения, а не в его тексте).

## Установка

1. В SillyTavern: **Extensions → Install Extension**.
2. Вставить URL этого репозитория: `https://github.com/ka-reli/emodiary`.
3. Убедиться, что в настройках ST разрешён показ HTML в сообщениях
   (User Settings → Forbid External Media / рендер HTML — по вкусу).

## Настройка

Открой **Extensions → ☽ Эмо-дневничок**:

1. **Эндпойнт** — базовый URL OpenAI-совместимого API вместе с `/v1`,
   например `https://openrouter.ai/api/v1` или `http://127.0.0.1:5001/v1`.
2. **API-ключ** — ключ провайдера.
3. Нажми **«Проверить подключение»** — расширение сходит в `/models`
   и заполнит выпадающий список моделей.
4. Выбери модель (или впиши id вручную) и нажми **«Проверить модель»** —
   уйдёт крошечный тестовый запрос.

> ⚠️ Запросы идут напрямую из браузера, поэтому провайдер должен разрешать
> CORS (OpenRouter, OpenAI, локальные бэкенды — ок).

## Что умеет

- **Автозапись к каждому сообщению персонажа** (и опционально — юзера).
- **Чей дневник**: рандом (персонаж / персона / НПС / окружение),
  «модель решает по контексту» или фиксированный выбор.
- **Язык дневника**: русский или английский (настройка в разделе «Генерация») —
  эстетика в обоих случаях западная: LiveJournal, MySpace, Xanga.
- **Длина записи**: от крошечной (1–3 строки) до развёрнутой (10–16 строк),
  по умолчанию короткая.
- **Контекст дневникописца**: настраиваемая глубина последних сообщений,
  карточки персонажей, персона игрока, пара прошлых записей —
  чтобы дневник читался как цельный блог.
- **Случайные детали для вдохновения**: тема оформления, «вайб», счётчики
  просмотров и гостей подмешиваются в промт, чтобы каждая запись удивляла.
- **Редактируемый промт** с кнопкой сброса на стандартный.
- **Просмотрщик**: пункт «Эмо-дневничок: все записи» в меню расширений (палочка)
  открывает панель со всеми записями текущего чата подряд, как настоящий блог.
- **Ручной режим**: пункт «запись к последнему» в меню палочки, а на каждом
  блоке — кнопки ↻ (переписать) и ✖ (вырвать страницу).
- При свайпе сообщения запись переписывается под новый вариант.

## Безопасность

Ответ модели прогоняется через DOMPurify: `<script>`, `<style>`, `<iframe>`
и обработчики событий вырезаются, остаётся только безобидная инлайновая
вёрстка.
